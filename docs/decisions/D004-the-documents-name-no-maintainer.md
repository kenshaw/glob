# D4. The documents name no maintainer

Status: Decided.

The maintainers decided on 2026-11-26 that the documents of this repository
do not name a maintainer. A document says "the maintainers" for a choice and
"a maintainer" for a request. A document that names a person of upstream says
"upstream" or "the reporter". The same holds for a code comment and a commit
message.

The copyright line of `LICENSE` names its holder, and it stays, because a
license needs one. The history of git keeps the old names.

This follows magic D32.
